## Getting Started

1. First, do,
```bash
npm install
# or 
yarn install
```

2. Then, run the application using,
```bash
npm run dev
# or
yarn dev
```

3. Now, Open [http://localhost:3000](http://localhost:3000) with your browser to see the website.
